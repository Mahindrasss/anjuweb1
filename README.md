# Anju Coaching Center Website

Modern, professional, responsive website for **Anju Coaching Center** (Sector 86, Gurgaon, Haryana) focused on **CBSE Maths Classes 6th–10th**.

## Saved Project Files

```text
.
├── index.html         # Home page
├── about.html         # About Us page
├── courses.html       # Courses + syllabus page
├── results.html       # Results highlights page
├── testimonials.html  # Parent & student testimonials page
├── contact.html       # Contact page with form + map
├── style.css          # Shared styles (blue/white/yellow premium theme)
└── script.js          # Shared JS (animations, form validation, scroll-to-top)
```

## Features Included

- Sticky navbar with mobile-first responsive layout
- Hero section with CTA buttons: **Book Free Demo Class** / **Call Now**
- Trust elements:
  - **100% Concept Clarity Guarantee**
  - **Weekly Test Reports to Parents**
  - **Limited Seats Available** urgency block
- Class cards for 6th to 10th
- Results highlights, testimonials, FAQ
- Working contact form (client-side validation)
- Google Map embed (Sector 86, Gurgaon)
- WhatsApp floating button + scroll-to-top button
- SEO meta tags + Google Font (Poppins)
- Smooth reveal animations

## Run Locally

```bash
python3 -m http.server 4173
```

Then open:

- http://127.0.0.1:4173/index.html
